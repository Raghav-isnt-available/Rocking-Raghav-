Mandarin Quizlet Sets

Copy each set into Quizlet's import box. Each one takes about 30 seconds.

Importing one set

  1. On a computer, open Quizlet's create page.
  2. Click Copy title below and paste it into the set's title field.
  3. Click Import in Quizlet, then click Copy cards below and paste into the import box.
  4. Set Between term and definition to Tab and Between cards to New line, then click Import.
  5. Set the term language to Chinese (Simplified) so Quizlet reads the characters aloud, then click Create.

Each card has the characters on the front, and the pinyin and English on the back. To practise saying words, turn on "Answer with term" in Quizlet's study settings.

Sets from your textbook will go first in this list. Paste the pages into a Claude Code session in this repository and they'll be added as their own sets.
